About

This project started as a text summariser that used a Restricted Boltzmann Machine (RBM) written in Theano. Theano is not maintained anymore and does not install on new Python versions, so the RBM step was replaced with PCA from scikit-learn which does a similar job of cleaning up the feature scores.

Built with

  • Flask for the website and the API
  • NLTK for tokenising, POS tagging and named entities
  • scikit-learn and NumPy for the feature enhancement

Limitations

  • Only works well on English text.
  • It can only pick sentences, it cannot rewrite them.
  • Very long texts are slow because every sentence is compared to every other sentence.
