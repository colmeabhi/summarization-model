# How a request flows through the code

## 1. Request comes in
- Website: POST /  (routes/pages.py -> home)
- API:     POST /api/summarize  (routes/api.py)
- Old API: POST /post_summary   (routes/api.py)

routes/utils.py check_text() makes sure the text is not empty and not longer
than MAX_TEXT_LENGTH (config.py). Then summarize(text, ratio) is called.

ratio comes from the length option: short = 0.3, medium = 0.5, long = 0.7

## 2. summarygenerator/summary.py -> summarize()

    text
     |
     v
    split_into_sentences()          preprocessing.py
     |
     |  less than 3 sentences? -> return them as they are
     v
    build_feature_matrix()          summary.py
     |   remove_stop_words()        preprocessing.py  (lowercase, stopwords, porter stemmer)
     |   posTagger()                preprocessing.py
     |   8 features                 features.py + entity.py
     v
    matrix of shape (sentences x 8)
     |
     v
    score_sentences()               summary.py
     |   enhance_features()         feature_enhancer.py (StandardScaler -> PCA -> back, small fixed-seed noise)
     |   sum each row
     v
    pick_sentences()                summary.py
     |   always keep sentence 0
     |   sort by score (lowest first, same as the original project)
     |   keep int(n * ratio) of them
     |   put them back in the original order
     v
    dict with summary + counts -> template or json

## 3. The 8 features (columns of the matrix)
1. thematicFeature     - words from the 10 most common words in the text
2. sentencePos         - cosine based position score
3. sentenceLength      - 0 if under 3 words, otherwise length / longest sentence
4. properNounScores    - share of NNP / NNPS tags
5. numericToken        - share of tokens that are numbers
6. namedEntityRecog    - number of named entities (nltk ne_chunk)
7. tfIsf               - term frequency * inverse sentence frequency
8. centroidSimilarity  - cosine similarity to the sentence with the best tf-isf
